## 模拟和 mock 的范围

CPU/4 GB 策略有本机依据；8 GB、24 GB 和不兼容驱动仅用构造数据验证推荐策略，不记为硬件实测。

知识接口使用真实回环 HTTP 配合模拟响应，验证选中文字、有效/无效引用、材料不足、401、429、超时、无效 JSON 及超过 8 MiB 的 chunked 响应。安装版也用明确标记为“模拟接口验证”的本机服务测试 UI 到 Rust 到 HTTP 的引用笔记流程。这些不是云端模型质量测试。

## 仍需验证

1. 未提供真实云端 API 配置与密钥：实际服务商兼容性、摘要/问答质量、计费和额度未测试。
2. 未建立人工参考转写：中文 CER 和术语准确率没有结果。现有转写能见到“经济网络”等疑似误识别，需要回听校对。
3. 更长课程、中英混合、背景噪声、多模型对照仍需增加样本；已有测试不能代表所有材料。
4. 未在其他显卡或第二台干净 Windows 上安装验证。隔离 PATH 与空依赖设置测试不能替代完整干净系统测试。
5. 安装包未使用商业代码签名证书。额外 CPU 环境安装脚本提供独立安装路径，未覆盖所有 Python、网络镜像和驱动组合。

在这些边界内，应用可用于本机的课程导入、文字校对、可追溯笔记与导出。后续跨课程语义检索、更多 ASR/GPU 后端与专用平台适配不作为当前已交付能力。
