# 产品与首版范围

个人本地课程工作台，服务“导入 → 获取字幕或转写 → 校对 → 笔记 → 检索/问答 → 导出”。不引入团队角色、协作审批、账户系统或远程资料库。

当前 v0.2.0 支持 B 站单视频与明确选择的分 P、yt-dlp 可解析的其他网站单视频与 HTTP(S) 音视频直链、本地音视频、SRT/VTT/B 站字幕 JSON。本地入口支持原生文件选择、单文件拖入和绝对路径；“上传”仅指导入本机。原始媒体和全文索引保存在用户电脑。AI 摘要和单课程问答由用户配置 OpenAI 兼容接口并主动提交；可用本机兼容服务，但应用不负责安装本地大模型。

## 用户路径

1. 确认存储目录；复用已有 Python、Whisper、模型和 FFmpeg，或配置独立环境。
2. 读取链接信息，检查时长、分 P、字幕状态，选择处理范围。
3. 字幕优先。可读取字幕不启动音轨下载/ASR；仅字幕遇到登录、缺失或失败时返回对应原因。
4. 无可用字幕时优先获取独立音轨；未提供独立音轨的来源预先提示下载媒体后提取音频。强制转写显式产生新的文字版本。
5. 以片段时间戳查看、搜索、回听和校对。没有本地音频时跳转来源网页；B 站、YouTube、Vimeo 与直链使用各自时间定位形式，其他网站打开原页面。需要时单独获取回听音频。
6. 选择原文，写手动笔记或生成 AI 材料。引用固定到生成时的文字版本，修订后提示旧笔记可能过时。
7. 导出文字或字幕；Markdown 包含与选定版本绑定的笔记及引用。

## 明确边界

- 资源档位给出候选配置，实际跑过的样本才标为“实测”。更大的模型不自动等于更高中文准确率。
- 通用网站支持受 yt-dlp 版本及登录/网络条件影响，不承诺任意网站；播放列表、直播、预约与 DRM 来源拒绝导入。仅支持一次一个本地文件，多文件拖入明确提示逐个处理。
- 一次只运行一个转写任务。未验证更高并发，不按显存总量自动增加任务数。
- 网络、模型或 API 故障不删除已有文字。取消和退出保留已完成的音频块，重试复用相同配置的检查点。
- 数据目录切换打开另一份资料库，不自动移动原来的库；已有模型共享目录只读清理。
