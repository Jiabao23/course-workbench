# 转录核对与 Obsidian 本地桥接

用户要求实现两项功能并形成测试闭环。以现有个人工作台为基础，不引入云端依赖。选用本地规则核对和无插件 Markdown 桥接；全量第二模型重识别成本较高，双向修改数据库会带来冲突，均不作为默认实现。

## 转录核对

阅读器自动检查所查看的不可变文字版本：头尾遗漏候选、超过 15 秒的内部无文字间隔、异常时间轴、空文字和连续重复文字。显示时间轴覆盖率（明确不是识别准确率），缺少独立来源时长时显示证据不足，不能从字幕末尾反推课程完整。

通过数据库现有 job_transcripts 关系读取对应任务，核对 ASR 分块总数与已完成数。新转写在完成数不足时拒绝提交“完成”结果；保留检查点供重试。检查还比较下载前来源时长和转换后媒体时长，差异超过 max(5 秒, 2%) 时提示来源可能截短。编辑版本没有独立分块证据时如实显示，不借用其他任务的完成标记。

异常项可定位回听/打开来源；用户可保存带说明的人工核对记录。记录绑定版本及整个检查依据摘要，获取音频或时长变化后不继承旧确认。结果始终说明规则检查不能证明逐字无遗漏。可校对保存新版本或重新转写；新版本重新检查，旧版本和引用保留。

## 本地知识库

设置支持选择已有 vault 或初始化明确指定的独立文件夹。只创建本应用的 CourseWorkbench 子目录和新 vault 的空 .obsidian 目录，不安装社区插件、不改变其他配置。目录检查拒绝重解析链接和越界写入。

每次主动同步当前所查看版本的文字、绑定笔记、核对报告和来源，生成内容摘要命名的 Markdown 快照。重复同步相同内容不重复写入；源文或笔记变化创建新快照。文件已存在但被用户修改时报告冲突并保留原文件，不覆盖。课程目录个人笔记只创建一次，后续原样保留。索引只追加新链接，保留用户已有内容；快照写成功后再发布索引链接。中断后重试可恢复，不出现链接指向尚未写完文件。

课程和版本 ID 生成文件路径，标题仅用于正文，避免同名覆盖和路径注入。原文片段使用 Obsidian 块标识，笔记引用定位到对应快照片段。使用官方 obsidian://open?path= URI 打开当前课程索引；未安装或未注册 vault 时给出可执行的操作说明，Markdown 仍可本地阅读。音视频不默认复制进 vault。

## 验收

构造时间轴缺口、重复、未知时长、丢失分块和媒体截短；真实短样本与已有课程运行核对。保存人工结论、重启读回、更换版本不串结论。vault 实测中文/空格路径、重复导出、追加笔记、新版本、历史引用、用户修改文件冲突、只读/缺目录和链接目录拒绝。验证所有生成引用能找到实际块。执行 Rust/Python/前端测试、fmt、clippy、前端构建、Windows 打包。区分规则、夹具、真实桌面、实际 Obsidian 验收。
