# 个人知识库分类与三种主题

在当前本地资料库中建立逻辑知识库，知识库下可建立文件夹/分组（支持嵌套，最多 8 层）。课程只有一个分类归属，收藏状态独立；默认旧资料与新导入资料均在未分类。全部资料、未分类、收藏、选定分类含下级、标题筛选可组合查看；支持逐项收藏、批量移动、分类重命名，只有空分类可删除。分类不移动或删除媒体、文字版本、笔记、Obsidian 快照；Obsidian 继续使用既有稳定课程路径。

采用独立 collections 与 asset_organization 表，SQLite schema 4，保留 Asset 协议和已有数据。同级分类名去首尾空白并忽略大小写去重。不存在的目标或课程使整批移动失败，保持原归属。删除非空分类拒绝，分类 ID 不随重命名变化。分类树当前不支持拖拽重排或移动文件夹，课程可随时移动至其他知识库或未分类。

将 App 内资料库列表提取为 LibraryView，业务写入仍通过类型化 Tauri 命令和 Runtime mutation gate。分类与收藏存入数据库，重启或数据目录切换后以当前数据库为准。阅读返回保留分类筛选；切换资料目录重置选择。编辑分类名称与批量选择的交互不套用到其他资料库。

主题：forest 森林浅色、paper 暖纸米色、night 深海夜色。存入 AppSettings，老设置默认为 forest；设置页可即时预览，保存后重启生效，放弃修改恢复原主题。统一 CSS 色彩变量覆盖列表、阅读器、设置、弹窗、提示与焦点状态；夜色同步原生控件 color-scheme。启动前只缓存主题标识以避免闪白，不储存内容。

验证：数据库迁移、分类树/重名/空名/层级上限、原子移动与收藏持久化、分类删除保护；真实桌面导入到未分类、建立知识库和文件夹、批量归类、收藏筛选、阅读和旧引用、重启；三种主题全页截图、文字对比度、保存/放弃/重启。发布前备份实际数据库，打包与独立安装验证，Git 推送并区分 CI 状态。

补充已确认交互：逐条或批量打开“收纳到…”面板，选择知识库/分组，支持在面板内新建分支并选中，再显式确认移动。未保存名称关闭确认，创建后的分类立即保留。左侧分支箭头折叠和省略号菜单；主导航与“全部资料/我的知识库”分类列分别独立收起、记忆布局。分类列收起保留窄入口及键盘焦点，当前筛选不变。

动态优化：220ms 布局过渡、140ms 分支/菜单淡入、箭头旋转、星标确认及选中行反馈；保存时明确状态且阻止重复提交。prefers-reduced-motion 下禁用动画与过渡。真实 WebView2 验证连续点击、键盘、最小窗口与减少动态效果；不以动画完成作为业务成功依据。
