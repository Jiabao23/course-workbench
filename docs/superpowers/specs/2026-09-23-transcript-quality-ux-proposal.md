# 转录质量与简化交互：建议方案

状态：用户已确认并实施为 v0.5.0。设计基线 v0.4.0，dae4879；实际验证与未测边界见 ../../validation-quality-ux-0.5.0.md。

## 设计时的基线事实

- integrity.rs 已检查分块完成、来源/媒体时长、头尾空白、中间超过 15 秒空白、重叠、重复和越界。
- 已保存核对结论绑定文字版本和证据摘要，旧版本与引用保留。
- 没有独立语音活动检测，无法区分真实静音与有讲话但无字幕。
- worker 当前规范化结果只保留片段信息，没有将 Whisper 的 avg_logprob、no_speech_prob、compression_ratio 作为诊断证据持久化。
- 人工结论是报告级文本，缺少每条疑点的处理状态；有结论时摘要显示“已记录人工结论”，未同时显示剩余疑点数量。
- 阅读器同时呈现版本、校对、质量、回听、搜索、片段选择、笔记和同步入口，存在精简空间。

## 推荐路线与替代方案

推荐分层核查：默认执行轻量规则；有本地音频时增加 CPU 语音活动检测；仅对疑点按需二次识别。先用基线样本验证误报和成本，再确定阈值。

仅强化现有时间轴规则成本最低，但不能覆盖“有讲话却漏转”；全程双模型识别成本较高且两个模型可能犯相同错误，不作为个人设备的默认路径。

## 质量检查设计

1. 处理完整性：下载/转换时长、分块完成、输出提交仍沿用既有检查。检查失败不得发布为完成任务。
2. 疑似漏转：将语音活动区间与文字时间区间比较。连续讲话而没有文字时提出疑点；正常静音/片尾降级展示。语音检测也可能出错，不能将其作为逐字完整的证明。
3. 疑似错字/幻觉：持久化 Whisper 诊断值，结合异常重复等规则排序。低分不是错误判决，也不得转换成未经标定的“准确率百分比”。旧数据无诊断值时标记证据不足，不自动重跑。
4. 单项复核：每个疑点有“待核对 / 已确认正常 / 已修订”，记录理由、时间、文字版本与检查依据。保存一条总结不清空其余疑点。
5. 修复流程：点击疑点播放其前后上下文；支持手动校对生成新版本。后续增加选定区间二次识别、原文/候选差异对照，由用户决定是否采用。不得自动覆盖原文；采用后新版本记录区间来源、模型及父版本，历史笔记仍指向旧出处。

质量摘要分开显示“处理状态”和“核对状态”，例如“处理完成 · 3 处待核对”。没有本地音频时明确显示“仅时间轴检查”，不默默下载音轨；提供获取音轨后检查入口。处理完成不等于内容正确。

资源策略：VAD 优先 CPU；二次识别复用已验证配置，与现有 ASR 共用 GPU 单任务队列。新模型需要展示下载量并验证。检测缓存绑定音频内容摘要、检测器/规则版本，修改原文或证据后重算相关结果，旧人工确认不能套用。

## 简化界面

- 阅读器默认突出文字和回听；笔记侧栏可收起，记忆布局。
- 顶部保留“校对”“笔记”“更多”。导出、Obsidian 同步、历史版本等放入更多菜单，保留清楚的文字名称和键盘访问。
- 用一行质量摘要替代常驻展开的详细指标。点击后在同一辅助侧栏切换到“核对”，避免再叠加一列；按疑点定位、处理、进入下一项。
- 普通阅读隐藏逐段复选框；主动进入“摘录/选择片段”后显示选择工具，退出时明确处理选择状态。选中内容仍是 AI 请求的唯一范围。
- 同一页面合并重复解释和成功提示；错误保留原因、重试与可用替代操作。未保存保护、引用跳转、取消任务不可因精简而消失。
- 使用已有短动效和减少动态效果支持，不新增持续闪烁或强制动画。

## 实施顺序与模块

A. 报告级改为逐项复核状态，质量摘要保留待办数；完成阅读器信息层级与侧栏切换。涉及 integrity.rs、数据库迁移、IntegrityPanel、Reader、类型契约。

B. 新增独立语音检测 worker/缓存与质量证据结构，扩展 ASR JSONL 的可选诊断字段，旧检查点和旧版本继续可读。VAD 检测失败时保留基本检查，不能显示“检查通过”。

C. 局部复听、二次识别、候选比较与显式采纳，采用新版本/分段来源记录，加入取消恢复与过期候选保护。

每一步独立可交付；不要一次加入全程双模型、术语库、自动润色和新质量仪表盘。

## 验证与验收

- 基线《课程目标》人工标注一份参考稿，包含术语；另选长静音、真实漏转、重复、低音量和中英混合样本。
- 在真实转写副本中故意移除头部/中间/尾部片段，确认疑点可定位；正常停顿和片尾样本衡量误报。构造数据仅验证规则，不算真实识别质量实测。
- 报告疑点召回与误报；中文 CER 在固定标点、空格与繁简规则下计算；术语单独记录。诊断分数不能替代参考稿评估。
- 测试无音频、无诊断值、检测器缺失/失败、超时、取消、重启恢复、音频改变、文字新版本，以及陈旧候选拒绝提交。
- 验证确认一条疑点不隐藏其他待办；校对生成新版本而旧笔记仍跳到正确原文。
- 实测 VAD 与局部复核的时间、RAM/VRAM；本机 RTX 3050 4GB 测量不外推其他设备。
- 真实安装版测试完整路径：导入→质量摘要→疑点回听→校对→保存→导出/Obsidian；检查所有旧入口仍可达、三主题、1000×700、键盘焦点、减少动态效果及未保存保护。
- 实施后的验收证据另见 v0.5.0 验证记录；人工参考稿、CER 与召回/误报率尚未完成，不把它们标为已验证。
