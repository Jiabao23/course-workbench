# 个人使用指南

## 从一条课程开始

打开“课程工作台”，先在设置确认资料与模型目录。点击“导入课程”，选择来源：

- **B 站链接**：粘贴视频链接/BV 号，读取后核对分 P、时长和字幕状态。默认只勾选第一 P，需要多节课时逐项勾选。
- **其他视频网站**：粘贴完整的 HTTP(S) 单视频网页或音视频直链，点击“读取”。网站是否可用以实际解析结果为准；播放列表、直播和受内容保护的视频暂不导入。
- **本地文件**：点击选择音视频或字幕文件，也可拖入一个文件或粘贴绝对路径。选择/拖入后自动读取信息，再点“开始处理”。一次一个文件，多文件拖入会提示逐个导入；不会上传到服务器。

支持 MP3、WAV、M4A、MP4、MKV、FLAC、OGG、AAC、OPUS、WEBM、MOV、WMA，以及 SRT/VTT/B 站字幕 JSON。字幕文件需为 UTF-8 编码。解析和转写是两步：读取预览不会开始处理整套课程。

- **字幕优先**：能读到字幕时直接保存；否则获取可访问的媒体并转写。默认优先独立音轨，只有混合音视频时会事先提示下载原媒体后提取音频。本地音视频直接从选定文件提取音频。
- **仅提取字幕**：不会下载媒体或启动语音识别；登录、缺失、失败分别提示。本地音视频需要独立字幕文件才能使用此模式。
- **重新转写音频**：使用当前设置重新识别，生成独立文字版本。

需要登录的网站可以在“设置 → 资料与工具 → 网站 Cookie 文件”配置本人导出的 Netscape Cookie 文件；程序按域使用 Cookie，不用于 AI 请求。没有相应网站记录时按匿名访问处理。遇到登录或验证要求时不会尝试绕过；更新 yt-dlp、补充有效 Cookie，或导入已有本地文件。

通用网站使用 [yt-dlp](https://github.com/yt-dlp/yt-dlp)。本机已验证 YouTube《Me at the zoo》的英文字幕直提；Vimeo 测试视频要求登录，TED 测试链接解析失败。支持列表只说明存在解析器，不保证每条链接在当前网络和账号条件下可用。需要 JavaScript 的网站还需安装 Node.js 并重新启动工作台，其他来源和本地文件不依赖它。

## 校对、回听与版本

点击资料行打开文字稿。时间戳可回听本地音频；网页资料未缓存音频时会打开原视频，也能点击“获取本地回听音频”。B 站、YouTube、Vimeo 和音视频直链会附带时间定位，其余网站打开原页面。纯字幕文件没有音轨。

点击“校对”，修改后“保存新版本”。旧版保留在版本选择器中，旧笔记仍引用当时原文。可以查看或设定历史版本为当前版本。已有笔记若关联旧版本，会显示原文更新提示。搜索索引跟随当前活动版本。

## 笔记和问答

勾选左侧片段，在“写笔记”中手写或摘录。保存后点击引用即可回到对应版本和片段。

AI 整理需要在设置中填写 OpenAI 兼容 API 地址（例如服务商的 `/v1` 地址）、实际模型名及密钥。免密本机服务可留空密钥。界面会显示将发送的片段数、字符数和服务地址；点击生成才发送。可以整理摘要/提纲/概念/学习笔记，或提出一个单课程问题。超过上限需缩小选择，不自动截断。

引用对应真实片段不代表每个生成结论必然正确；应对照原文检查。材料不足、限流、密钥错误、超时不会影响已有文字与笔记。

## 搜索与导出

顶部搜索框或 Ctrl+K 检索本地原文，点击结果定位时间戳。阅读器中的搜索只筛选当前文字稿。

“导出”可选择 TXT、Markdown、SRT、VTT。Markdown 同时导出所查看版本的笔记和引用，可用于 Obsidian 等支持 Markdown 的工具。导出旧版本时只包含绑定该旧版的笔记。

## 核对转录是否齐全

在文字稿上方展开“转录完整性核对”。程序检查任务分块是否完成、来源与本地媒体时长是否一致，以及开头、结尾、长空白、重叠、重复和异常时间戳。

点击疑点时间可回听，未缓存音频的网页课程会打开原来源。确认是静音、片尾或漏转后，填写核对结论并保存；仍有漏转时，可“重新转写为新版本”，再对照校对。原文和历史笔记保留。重新转写使用当前识别设置，对网页来源可能重新获取媒体。

“时间轴覆盖”是字幕占用的时长比例，**不是准确率，也不能证明逐字齐全**。没有字幕的时间可能是静音，也可能是漏转。仅字幕文件缺少独立媒体时长，无法证明头尾齐全；旧任务缺少关联分块证据时会明确提示。人工记录绑定当时的文字版本与检查依据，改成新版本或获取新的音频后需要重新核对，旧记录不被套用。未保存的核对结论会阻止同步和进入校对。

## 用 Obsidian 搭建独立课程知识库

1. 在“设置 → Obsidian 知识库”填写独立文件夹，例如 `D:\CourseWorkbenchKnowledge`，保存后点击“初始化 / 检查知识库”。
2. 在 Obsidian 中选择“打开文件夹作为仓库”，打开同一目录。无需社区插件或云端同步服务；未安装时可使用设置中的官方下载入口。
3. 在课程阅读页选择要同步的文字版本，保存校对、笔记和核对结论，点击“同步到 Obsidian”。
4. 点击“在 Obsidian 打开课程”。知识库入口为 `CourseWorkbench/课程索引.md`；课程索引链接到各次快照。可以在 Obsidian 中全文搜索、分类和建立双向链接，笔记中的“原文依据”跳到当时的原文块。
5. 把自己的补充写进课程目录的 `个人笔记.md`。再次同步不会覆盖它；同样的内容不会重复生成快照，内容变化则新增快照，保留旧出处。

同步包含当前查看版本的文字、对应笔记和完整性报告；不复制音视频，不上传云端，也不会把 Obsidian 中的修改反向写回工作台数据库。如果直接修改生成的快照，再同步相同版本会提示冲突；请先保留自己的修改，并将冲突快照移走后重试。课程索引允许补充分类，但需保留文件开头的工作台标记。不要把知识库目录放在目录联接或符号链接下面。

## 长任务和缓存

任务页可取消、按原配置重试，或调整设置后按新配置重试。退出应用保留完成的转写块；重启后遗留任务显示待恢复。默认每块五分钟，未完成的那一块重跑。

设置中的缓存清理按音轨、回听音频、检查点、临时文件、日志和自有模型分别执行。清理检查点后无法复用中间进度；清理回听文件后可以重新获取。共享模型目录不提供删除。

备份时先退出应用，再复制整个资料目录。API 密钥不在资料目录中，换电脑时需要重新配置。修改资料目录只切换资料库，不自动迁移数据。

## 知识库、分组与收藏（v0.4.0）

在资料库右上角“新建知识库”，进入知识库后“新建分组”；支持最多 8 层（含知识库）。左侧箭头展开/收起分支，省略号弹出新建子分组、重命名和查看操作。同一级名称不能重复。

课程行点击“收纳到…”，或勾选多条后“收纳所选”。在弹出面板选择知识库/分组，也可直接新建知识库或子分组；新建后自动选中目标，点击“确认收纳”完成归类。新建分类立即保存，取消收纳不会删除它；填写到一半的名称关闭时会确认。保存中显示进度，禁用重复提交。

星标收藏独立于分类，可与当前分类、标题筛选一起使用；选择上级包含所有下级课程。新资料先进入“未分类”。重命名不影响归属，只有空分类可删除；需先移出课程并删除空子分组。分类不搬动音视频、文字和笔记，也不改变 Obsidian 快照路径。应用知识库是同一资料目录内的逻辑分类，不是多个 Obsidian vault。

“分类导航”旁的收起按钮隐藏整块分类栏，保留窄入口，课程区域随之加宽；展开仍保留当前筛选。顶部按钮可独立收起主导航。两种布局偏好分别记忆；刷新/重启重置临时筛选，阅读返回保留筛选。使用键盘收起分类栏后，焦点保留在展开入口，可按 Enter 再展开。

## 三种主题与动态反馈

在“设置 → 外观主题”选择森林浅色、暖纸米色、深海夜色，可即时预览；保存后下次启动继续使用，放弃设置恢复已保存主题。

侧栏使用约 220 毫秒的伸缩过渡，菜单与分支使用短淡入，星标、选中行、按钮给出操作反馈。遵循 Windows 的“减少动态效果”偏好；关闭动画不会延迟收纳、保存或键盘操作。

## 按疑点核对与局部重识别（v0.5.0）

阅读页的一行质量摘要显示待核对数。点击后在同一侧栏切换到“核对”，
默认只看待办；取消勾选可查看信息提示和已处理记录。旧版整体结论保留为
历史记录，不会清空逐项待办。没有识别诊断或本地音频时会明确说明。

有本地音频并配置语音检测扩展后，点击“检测语音区间（CPU）”。检测会
提示连续讲话却没有文字的区间；静音提示降为信息记录，但仍可回听。
检测不能发现所有短漏字、同音错词和术语错误，也不是准确率测量。

逐项点击“回听前后文”，填写理由后确认正常，或保留待核对。需要修订时
可以校对并保存新版本；系统只把确实改动覆盖的识别疑点关联为已修订，
不会把无关空白、分块证据问题一并清空。

“局部二次识别”使用当前识别配置，包含上下文并扩展到完整片段边界，
总长最多 120 秒。结果先保存为候选，关闭页面或重启后仍可比较、放弃或
“采用并生成新版本”。采用前验证音频和基础版本未变化；采纳后的内容
仍需人工核对。旧原文、笔记与引用保留，禁止静默覆盖。运行中可取消，
取消不会产生半份候选；局部任务再次执行会重新识别该区间。

笔记和核对共用可收起侧栏，切换或收起保留草稿。普通阅读不显示逐段
选择框，点击“摘录 / 选择片段”后才选择要记笔记或发送给 API 的文字；
退出选择模式会清空选择。“更多”集中提供导出、Obsidian 同步和历史
版本，Escape 可收起菜单。同步快照包含逐项结论和证据状态，不覆盖个人笔记。
