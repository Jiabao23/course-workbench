2.4.1+cu118、Whisper small。Silero VAD 6.2.2 使用 CPU，torch 单线程。

匹配 torchaudio 2.4.1+cu118，不修改 `D:\bili2text` 环境。

《课程目标》基线 356.608 秒 WAV 的一次 CPU VAD 实测：19.338 秒（含
导入/模型加载），157 个讲话区间，合计 281836 毫秒。这个时长比例不是
内容完整率。尚未采集可比较的本轮 VAD RAM 峰值。

桌面验证副本故意删除 69.8–89.8 秒范围内 10 个原始片段：

2. 真实 VAD 后显示 6 项：新增 4 段“有讲话但缺少文字”的提示。
3. 对分块证据说明确认一项后剩余 5 项；收起/展开核对栏理由草稿保留。
4. 点击回听确实播放音频；局部 small/CUDA 重识别扩展到完整边界
   65.8–93.8 秒。候选先存库，重载页面后仍可见。另以 CLI 生成候选，进程退出后重新启动桌面，候选恢复且可放弃。
5. 显式采纳生成 v3，156 个片段；旧版 5 项区间疑点标记已修订并记录
   新版本 ID。新版本再做 VAD 后不再出现所构造的空白/漏转提示，
   分块证据不足仍单独提示。候选中出现“集权界网络”等错词，不能称为
   识别准确率提升。
6. 手动改字保存新版本成功。历史笔记仍能定位 v1 原片段；FTS 有结果，
   数据库 `integrity_check=ok`。
7. VAD 和局部识别均实际取消并可重试；最终构建在资源探测阶段取消后
   返回“原文未修改”，没有把取消伪装成依赖错误。完成/正常取消清理临时
   WAV；开发热重载强制终止曾留下一个临时文件，可由缓存清理移除。

## 交互与本地知识库

- 普通阅读无逐段选择框；进入摘录后可选，退出清空并隐藏选择框。
- 笔记/核对共用侧栏；笔记草稿切换后保留，保存成功。
- 更多菜单可键盘 Escape 收起并归还焦点；导出、同步、历史版本可达。
- 森林、夜色和暖纸主题阅读可用；夜色/暖纸 1000×700 与减少动态效果模式无横向溢出。
- 无音频 P2 明确仅时间轴检查，VAD 禁用，提供获取音频入口而不自动下载。
- 实际导出 Markdown，保留原笔记的 5 条来源时间链接；独立 vault 初始化、
  v3 文字与核对报告同步成功。没有调用真实云端知识模型。
- 草稿遇到证据改变、检测器失效、候选过期/重复提交、事务失败回滚、
  历史证据保留等由自动化与代码审查覆盖；未全部在真实桌面逐项注入。

## 明确边界

尚无人工逐字参考稿，因此没有 CER、术语准确率、漏转召回/误报率结果。
未覆盖其他硬件、所有噪声/混合语言材料或第二台干净 Windows。
VAD 针对连续较长的无文字讲话，无法保证短漏字、同音词和术语正确。
二次识别是候选而非自动纠错；更大的模型也不等于更准确。
